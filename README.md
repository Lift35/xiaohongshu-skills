# 小红书内容创作 Skills

一套面向小红书知识内容的可复用工作流，从模糊主题开始，逐步完成详细大纲、逐字稿与轻量分镜、封面设计和发布前合规审核。

仓库目前包含 5 个 Skill。它们既可以独立使用，也可以由「小红书内容总控」根据当前材料和目标安排调用顺序。

## 推荐工作流

1. **判断起点与目标**：由「小红书内容总控」识别当前阶段、已有材料和本次交付终点。
2. **组织内容**：用「内容结构化创作」把主题、问题和资料整理成详细大纲。
3. **形成脚本**：用「知识视频脚本创作」把已确认大纲转成逐字稿与轻量分镜。
4. **实际制作（按需）**：制作演示稿、录屏、配音、剪辑和字幕。演示稿可以配合 Mac 录屏完成；这一环节目前不是仓库内的独立 Skill。
5. **设计封面**：核心内容稳定后，用「小红书封面」生成不同方向的封面方案与成图；可与实际制作并行。
6. **发布前审核**：成片、封面和发布文案齐全后，用「小红书合规官」检查风险；发现问题时，只返修受影响的环节并复核。

## Skills 一览

| Skill | 什么时候使用 | 主要交付 |
| --- | --- | --- |
| [小红书内容总控](./xiaohongshu-content-orchestrator-skill/) | 不确定从哪里开始，或希望完成一整套内容流程 | 阶段判断、调用顺序、确认闸门、交接状态和下一步行动 |
| [内容结构化创作](./xiaohongshu-content-outline-skill/) | 主题已确定，但只有零散问题、资料或观点 | 学习目标、详细大纲、案例安排、过渡和信息缺口 |
| [知识视频脚本创作](./knowledge-video-script-skill/) | 大纲已经确认，或已有逐字稿需要补分镜 | 自然可讲的逐字稿、轻量分镜、素材缺口和时长估算 |
| [小红书封面](./xiaohongshu-cover-skill/) | 内容价值、目标人群和可信依据已经明确 | 4 套真正不同的封面方向、推荐方案，以及环境支持时的独立成图 |
| [小红书合规官](./xiaohongshu-compliance-skill/) | 已有完整视频或小红书链接，并准备发布或整改 | 0—100 风险分、五项得分、问题位置、修改建议和发布建议 |

## 每个 Skill 是做什么的

### 1. 小红书内容总控

负责整套流程的**判断、编排和交接**。

它会先识别你已经有什么材料、希望做到哪一步，再选择对应的专业 Skill；同时维护受众、目标、核心观点、主案例、证据和待补项，避免不同阶段前后矛盾。

重要决策会设置确认闸门，例如主案例选择、大纲确认、脚本确认、封面方向选择和审核后的整改方案。它不替代其他专业 Skill，也不会擅自补造事实或发布内容。

示例：

> 使用小红书内容总控，从“什么是 Skill”这个模糊主题开始，帮我做到发布前审核。

### 2. 内容结构化创作

负责把**已确定的主题和零散材料，组织成适合观众学习的详细大纲**。

它会明确观众起点与学习目标，安排各章节解决的问题、核心要点、例子和过渡，并标出缺少的资料。若主案例会显著影响整期理解或画面设计，会先提供 2—3 个候选案例供用户选择。

它停在大纲，不主动调研事实，也不扩写逐字稿。

示例：

> 使用内容结构化创作，把“什么是 Skill”整理成一份 3 分钟知识视频大纲。

### 3. 知识视频脚本创作

负责把**已确认的大纲转成自然可讲的逐字稿，以及帮助理解的轻量分镜**。

支持三种模式：只写逐字稿、给已有逐字稿补分镜、两者一起制作。它会处理口语化、信息节奏、案例展开和声画配合，并继承上游尚未补齐的素材与证据缺口。

若贯穿多段的主案例尚未确认，它会先提供候选方案，而不会直接替用户决定。它不重新选题、不主动调研，也不制作演示稿或成片。

示例：

> 使用知识视频脚本创作，把这份已确认大纲转成逐字稿和轻量分镜，目标时长 3 分钟。

### 4. 小红书封面

负责把**稳定的内容价值转成具有点击意愿、同时不夸大承诺的封面方案**。

它会读取主题、内容、目标人群、核心价值和可信证据，默认交付 4 套真正不同的文案与视觉方向，并推荐其中一套；在支持图片生成时，交付 4 张独立封面供比较。

它不会编造权威、数据或效果，也不会只做四个换颜色的轻微变体。

示例：

> 使用小红书封面，为这期“什么是 Skill”生成 4 套封面方案和成图。

### 5. 小红书合规官

负责对**实际待发布材料进行发布前风险审核**。

主要输入是完整视频或小红书笔记链接，也可以补充封面、标题、正文、话题和预设评论。它会说明审核覆盖范围，输出总风险分、五项分类得分、问题时间点或位置、证据等级、最小修改建议和发布建议。

它提供风险判断，不代表平台官方审核，不保证一定过审，也不预测限流或流量表现。

示例：

> 使用小红书合规官，审核这个完整视频、封面和发布文案，并告诉我需要修改的位置。

## 如何选择

| 你现在的情况 | 建议使用 |
| --- | --- |
| 只有一个想法，不清楚下一步做什么 | 小红书内容总控 |
| 主题明确，但内容零散 | 内容结构化创作 |
| 已有确认的大纲 | 知识视频脚本创作 |
| 已有逐字稿，只缺画面安排 | 知识视频脚本创作的“只补分镜”模式 |
| 核心内容稳定，需要设计封面 | 小红书封面 |
| 视频、封面和文案已经准备好 | 小红书合规官 |
| 希望从任意阶段继续完成整套流程 | 小红书内容总控 |

## 共同边界

- 缺少事实、数据、案例结果或素材时，会明确标注，不为了完整而编造。
- 已确认的主题、核心观点和表述不会被下游 Skill 擅自改写；发现结构性问题时会先提出并等待确认。
- 演示稿、录屏、剪辑、字幕和发布操作属于实际制作阶段，目前不由本仓库中的独立 Skill 完成。
- 这些 Skill 不会代替用户发布、删除内容、发消息或发起申诉，除非另有明确授权并存在相应能力。
