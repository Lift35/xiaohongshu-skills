# 审核清单

以下为审查维度，不是已核验的官方完整禁令。具体定性须核对当前适用规则。

## 导流链路

识别“展示什么 → 要求用户做什么 → 去哪里 → 领取/购买/提供什么”。联合检查正文、画面、字幕、口播、评论、主页，不只删正文链接。

- 中性介绍工具、引用出处、教学偶现域名：不直接认定交易导流，看是否有行动引导。
- 免费开源下载、站外阅读：检查站外迁移、联系方式采集、商业漏斗；证据不足标待核实，不能套站外交易规则直接判死。
- 评论/关注换资料：检查奖励交换与互动要求，再检查领取去向，分别识别互动风险和导流风险。
- 加微信买课程、扫码外部付费群、私信转站外交易：优先提示高风险并核对导流条款。

优先建议在笔记内提供实质知识。交易需求可核实适用的平台官方工具，但不能假设用户具备权限，也不承诺有官方组件即可合规。

## 审查维度

| 维度 | 重点 | 防止误判 |
|---|---|---|
| 真实性 | 数据来源、效果承诺、测试条件、前后对比 | 区分修辞与事实承诺，不把所有“最”字当禁词 |
| 商业关系 | 商单、赠品、佣金、自营产品，披露及报备 | 自发推荐不自动是未报备广告 |
| 互动秩序 | 奖励换互动、虚假抽奖、刷量、骚扰、批量重复 | 正常讨论与收藏邀请不直接判违规 |
| 权利隐私 | 视频音乐字体肖像授权、个人信息、客户资料、密钥 | 缺授权材料应待核实，而非断言侵权 |
| 社区安全 | 色情低俗、仇恨攻击、网暴、危险行为、未成年人保护 | 分辨引用科普、批评与实际鼓动 |
| 高风险行业 | 医疗、金融、法律等建议及销售、身份资质、效果收益承诺 | 行业科普不自动等于无证经营；另核专项规则 |
| AI合成 | 生成合成范围、主动声明、显式/隐式标识、虚假经历身份新闻、合成肖像 | 不一概禁止AI辅助，不认为标识能消除虚假或侵权风险 |
| 内容一致性 | 标题封面是否兑现、断章取义、冒充官方 | “官方指南解读”不等于声称“官方授权” |

## AI / Skill 教程

检查录屏账号、API密钥、私人文件、浏览器地址和第三方水印。核对演示效果与普遍效果承诺的差别；核实开源授权与署名。“33页官方指南”应查页数和发布方，真实引用不自动是冒充官方。

## AI标识判断

- 先区分完全或部分生成合成、对既有内容润色/优化、普通后期编辑，以及没有改变真实性的工具辅助。记录用户计划使用的平台“笔记含AI合成内容”等声明功能；未提供发布设置时标待核实，不凭导出文件断言“未标识”。
- 《人工智能生成合成内容标识办法》第十条要求用户发布生成合成内容时主动声明并使用平台标识功能；现行《小红书用户服务协议》还要求对新技术制作的非真实信息显著标识，并禁止恶意删除、篡改、伪造或隐匿AI标识。事实与适用范围清楚时可按A级依据定性。
- 《社区公约2.0》进一步倡导：完全AI生成，以及AI润色、优化或获取灵感后的再创作，都尽可能在内容中清晰说明。这是披露范围更广的社区倡议；仅有轻度辅助且是否属于生成合成内容不清时，不把倡议直接写成固定处罚条款。
- 标识义务、内容真实性和权利授权分别审核。已经标识不能使虚假新闻、虚构经历、未授权肖像或抄袭内容免责；使用AI也不自动证明内容虚假、侵权或低质。
- 已确认恶意去除或伪造AI标识、或明确计划发布生成合成内容却不使用平台标识功能时，归入“社区安全及专项要求”并按实际严重程度评分。只有未提供发布设置时保持待核实，不以0分掩盖缺口。

整改示例仅说明行为，不是平台保证安全的句式：
- “点赞关注后加微信领资料”：取消交换和站外联系方式，在笔记内实际提供步骤；未附材料不能编造“资料已附”。
- “100%生成爆款”：改为真实可支持的演示范围，不编造测试数据。
- 仅参考资料却称“官方授权教程”：事实成立时改为“基于官方指南的个人实操”。
