# 荧光笔刷人物动作型

这是默认四套封面中的固定输出类型。目标不是简单使用绿色字体，也不是复刻某张参考图，而是用主题驱动的人物动作、关键道具和巨幅笔刷文字组成一个能在静帧中读懂的故事瞬间。

## 1. 固定视觉基因

- 小红书 3:4 竖版封面。
- 暗色、真实、与主题直接相关的生活或工作场景；背景压暗并轻微虚化。
- 人物以半身或中近景居中，占画面约 40%–60%，呈现明确情绪。
- 使用接近 `#E6FF00`–`#F4FF00` 的荧光黄绿色超大手写笔刷字，保留飞白、毛边和速度感。
- 使用“后景标题—中景人物—前景标题”的三层构图：顶部文字位于人物后方，少量笔画可轻压发丝或肩部；前景文字覆盖躯干边缘，但不遮住眼睛、关键表情和关键道具。
- 副标题使用较小的白色手写字或粗粝白字，明显让位于主标题。

## 2. 主题驱动动作

先把主题写成一句动作描述：

> 人物正在用「动作」处理「关键道具」，从而表达「内容结果」。

按内容选择动作，不把任何姿势固定为模板：

| 内容类型 | 优先动作 | 常用道具 | 适合表达 |
|---|---|---|---|
| 教程、制作 | 组装、操作、绘制、演示 | 电脑、文件、卡片、工具 | 从 0 到 1、完整流程 |
| 前后对比 | 撕开、翻页、揭示、并排比较 | 新旧方案、前后封面 | 优化、变化、反差 |
| 资源分享 | 递出、打开、展示 | 文件夹、模板、清单 | 免费分享、可直接使用 |
| 概念解释 | 连接、拆解、排序 | 积木、流程卡、关系图 | 原理、结构、步骤 |
| 测评排错 | 检查、对照、修复 | 放大镜、错误稿、测试面板 | 找问题、验证、修复 |

动作需要满足三个条件：与主题相关、静帧可读、能与道具发生真实互动。禁止把扶额、托腮、指太阳穴、仰头或普通微笑摆拍当作万能动作。

## 3. 使用参考图

把参考图拆成两类信息：

- **可继承**：色彩关系、字体气质、笔触、人物比例、文字前后层叠、光影与画面密度。
- **默认不继承**：人物身份、脸部、服装、具体动作、手势、视线、场景、品牌标识和原文案。

除非用户明确要求复刻姿势，否则提示词必须写明“不要模仿参考人物的动作、手势和视线”。

## 4. 生成提示词骨架

```text
小红书 3:4 竖版封面。暗色、真实且与主题相关的场景。人物以半身或中近景居中，呈现“[具体情绪]”，正在用“[具体动作]”操作“[关键道具]”，表达“[内容结果]”。采用“后景标题—中景人物—前景标题”的三层构图：顶部标题位于人物头部后方，少量笔画轻压发丝或肩部；前景标题覆盖人物躯干边缘，但不遮挡眼睛、关键表情和道具。主标题严格使用“[主标题]”，采用超大荧光黄绿色粗粝手写笔刷字；底部副标题严格使用“[副标题]”，采用较小白字。

参考图只用于色彩、笔触、人物比例和层叠关系。不要复制参考人物的身份、脸部、服装、动作、手势、视线、场景、品牌和文案。

禁止：扶额、托腮、指太阳穴、无主题的仰头、普通微笑摆拍、纯色科技渐变背景、绿色无衬线标题、悬浮 UI 卡片、密集小字、多个同级焦点、乱码、水印。
```

## 5. 验收

- 遮住标题后，人物动作与道具是否仍能大致表达主题？
- 动作能否写成清楚的“动词 + 道具 + 结果”，而不是一个通用姿势？
- 是否继承了参考图的视觉语言，却没有照搬人物姿势？
- 是否形成了“后景文字—人物—前景文字”的三层穿插？
- 主标题是否确实是荧光黄绿色粗粝笔刷字，而不是普通绿色字体？
- 是否避免遮挡人物眼睛、关键表情和关键道具？
