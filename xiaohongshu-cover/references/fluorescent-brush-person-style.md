# 荧光笔刷人物叙事型

这是默认四套封面中的固定视觉方向。目标不是“使用绿色字体”，而是用人物、场景、道具和巨幅笔刷文字共同制造一个有冲突或发现感的故事瞬间。

## 1. 适用方式

- 默认四套中固定生成 1 套。
- 主题、场景、人物情绪和关键道具随内容变化；视觉语言保持稳定。
- 用户明确禁用人物、指定四套均采用其他风格，或内容确实不适合人物表达时，可以取消并说明原因。

## 2. 固定视觉基因

### 场景

- 使用暗色、真实、与主题直接相关的生活或工作环境，例如咖啡店、办公室、工作室、书桌或拍摄现场。
- 环境保持可辨认，但压暗并轻微虚化，让人物、道具和标题成为焦点。
- 优先使用暖色局部光、电影感阴影和真实材质，不使用纯色或渐变科技背景替代真实场景。

### 人物与道具

- 人物占画面约 40%–60%，以半身或中近景为主。
- 人物必须呈现明确情绪：困惑、惊讶、发现、兴奋、自信等；根据封面钩子选择，不默认微笑摆拍。
- 人物必须正在观察、举起、操作或指向与主题有关的关键道具，让画面能独立讲出一个瞬间。
- 道具应具体并可识别，例如超长清单、电脑、封面草稿、文件夹、手机或产品实物；不要堆砌无关物品。

### 主标题

- 使用高饱和荧光黄绿色，建议色相接近 `#E6FF00`–`#F4FF00`。
- 使用超大、粗粝、带飞白和毛边的手写笔刷字，不使用规整黑体、无衬线体或发光 UI 字体代替。
- 主标题通常分成 2 个大块，整体占画面约 35%–50%；可以跨越画面或形成轻微斜向动势。
- 文字与人物形成前后层叠：部分笔画可以压在人物或道具前方，部分可以藏在人物后方。
- 不遮挡人物眼睛、核心表情和关键道具；缩小后仍应先读到主标题。

### 副标题与证据

- 使用白色手写字、粉笔字或粗粝白色黑体，尺寸明显小于主标题。
- 优先放在画面底部，与一至两条白色手绘横线组合；只保留一句副标题和必要的真实证据。
- 不新增彩色角标或悬浮卡片与主标题竞争。

## 3. 构图顺序

1. 先确定人物的情绪和关键道具，形成可读的故事瞬间。
2. 再将主标题拆成 2 个大块，分别放在画面上部和中下部。
3. 通过遮挡关系让文字与人物穿插，而不是简单把文字放在人物旁边。
4. 最后把白色副标题压在底部，并删除不影响理解的装饰。

## 4. 生成提示词骨架

```text
小红书 3:4 竖版封面。暗色、真实且与主题相关的场景，电影感暖色局部光。一个与目标人群匹配的人物以半身或中近景出现，呈现“[具体情绪]”，正在[观察/举起/操作/指向][关键道具]。主标题严格使用“[主标题]”，拆成两个大块，以超大荧光黄绿色手写笔刷字呈现，带粗粝毛边、飞白和速度感；文字与人物形成前后穿插，但不遮挡眼睛、表情和关键道具。底部副标题严格使用“[副标题]”，采用较小的白色手写字或粗粝白字，并配简洁白色手绘横线。保持单一视觉中心、强烈明暗对比和手机缩略图可读性。

禁止：紫色或彩色渐变科技背景、绿色无衬线标题、悬浮 UI 卡片、人物微笑摆拍、无关道具、密集小字、多个同级焦点、乱码、水印。
```

## 5. 验收

- 遮住颜色后，是否仍能从人物情绪和道具看懂主题？
- 主标题是否确实是粗粝荧光笔刷字，而不是普通绿色字体？
- 文字是否与人物产生了前后穿插，而不是简单左右分栏？
- 人物是否正在与关键道具互动，而不是无意义摆拍？
- 底部白色副标题是否清楚但不抢主标题？
- 是否避免了紫色渐变、悬浮 UI 卡片和普通科技海报感？
