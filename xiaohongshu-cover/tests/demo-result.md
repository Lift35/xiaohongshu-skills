# 示例测试结果：手把手制作小红书封面 Skill

## 一、输入理解

- 笔记主题：从 0 到 1 制作一个“小红书封面生成 Skill”
- 目标人群：已经听过 Skill 概念、准备开始实操的 AI 初学者与内容创作者
- 核心价值：学会把封面设计经验拆成 SOP，并写进 SKILL.md 反复调用
- 可信证据：真实制作过程；参考 Claude 官方 Skill 构建指南
- 必须保留的信息：小红书封面、Skill、SKILL.md、实操属性
- 当前推断与假设：这期内容的最大点击动力不是“什么是 Skill”，而是“终于开始亲手做一个 Skill”

## 二、4 套封面方向

### 方案 1｜反常识开场

- 点击动机：打破“写 Skill 就是先写文件”的直觉，制造好奇
- 主标题：做 Skill，先别写 SKILL.md
- 副标题：先把封面经验拆成 SOP
- 角标/可信标签：实操演示
- 信息层级：`先别写 SKILL.md` 最大；`做 Skill` 次级；副标题与角标弱化
- 版式：居中海报式，主标题分两行，`SKILL.md` 使用代码标签样式
- 画面建议：文件图标位于背景偏下，箭头从“经验”指向“SOP”再指向“SKILL.md”，但只作为辅助线索
- 可能有效的原因：主题清楚，同时保留认知冲突；与口播中的核心观点高度一致

### 方案 2｜结果教程型

- 点击动机：直接告诉用户看完能够完成什么
- 主标题：5 步做出封面 Skill
- 副标题：输入→SOP→编写→测试→迭代
- 角标/可信标签：从 0 到 1
- 信息层级：数字 `5` 最大；“封面 Skill”第二；流程做成底部小标签
- 版式：上下分区式，上方为标题，下方为五步流程卡片
- 画面建议：使用文件夹、文档和循环箭头三个核心图形，避免展示过多代码
- 可能有效的原因：收益明确，教程感强，适合搜索和收藏导向的用户

### 方案 3｜痛点转化型

- 点击动机：击中“每次做封面都重新想、结果不稳定”的问题
- 主标题：封面总要重新想？
- 副标题：把设计经验变成可复用 Skill
- 角标/可信标签：附完整 SOP
- 信息层级：问题句最大；“可复用 Skill”局部高亮；可信标签置于右上角
- 版式：左右分栏式，左侧凌乱封面草稿，右侧整洁的 Skill 文件结构
- 画面建议：用“混乱 → 稳定输出”的前后对比，突出复用价值
- 可能有效的原因：从用户痛点切入，比单纯介绍制作步骤更强调为什么值得学

### 方案 4｜成品展示型

- 点击动机：先展示最终产物，吸引想直接拿到模板的人
- 主标题：小红书封面生成 Skill
- 副标题：一份 SKILL.md，反复生成 4 套方案
- 角标/可信标签：完整结构
- 信息层级：“封面生成 Skill”最大；“4 套方案”做第二视觉点，但不能超过主标题
- 版式：卡片信息式，中间展示 `xiaohongshu-cover/` 文件夹结构，四张迷你封面围绕主体排列
- 画面建议：主体是 SKILL.md 文件卡片，四张封面只保留轮廓与不同构图，不放细小文字
- 可能有效的原因：产物可视化，能让用户在点击前知道视频不是纯概念讲解

## 三、推荐方案

- 推荐：方案 1｜反常识开场
- 推荐理由：它直接承接前两期“讲概念”后的实操转折，又把本期最重要的方法论——先拆 SOP、再写 SKILL.md——变成了点击钩子。比“教你做一个 Skill”更有记忆点，也更贴合口播内容。
- 建议保留的最终文案：
  - 主标题：做 Skill，先别写 SKILL.md
  - 副标题：先把封面经验拆成 SOP
  - 角标：实操演示

## 四、最终制作说明

- 画布与比例：竖版 3:4
- 核心视觉中心：`先别写 SKILL.md`
- 文字排版：主标题两行；`SKILL.md` 用代码块或文件标签强调；副标题缩小放在标题下方
- 主体画面：一个打开的文件夹，内部依次出现“经验”“SOP”“SKILL.md”三个节点
- 背景与配色：浅色或深色单一背景均可，只保留一种高亮强调色
- 字体气质：粗体无衬线，专业、直接、略带科技感
- 素材要求：文件夹、Markdown 文件、简洁箭头；无需复杂人物或场景
- 禁用项：大段代码、四张封面同时写满文字、多个同等醒目的高饱和色块

## 五、验收结果

- 手机缩略图可读：通过；主标题需要分两行
- 一秒理解：通过；能理解“做 Skill”与“先拆 SOP”
- 单一视觉中心：通过；必须压低文件结构和箭头的存在感
- 可信证据真实：通过；使用“实操演示”，不夸大官方背书
- 无多余元素：通过；仅保留文件夹、三个节点和少量箭头
- 封面与正文一致：通过
