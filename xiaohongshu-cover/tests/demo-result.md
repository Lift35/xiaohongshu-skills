# 示例测试结果：手把手制作小红书封面 Skill

## 一、输入理解

- 笔记主题：从 0 到 1 制作一个“小红书封面生成 Skill”
- 目标人群：已经听过 Skill 概念、准备开始实操的 AI 初学者与内容创作者
- 核心价值：学会把封面设计经验拆成 SOP，并写进 SKILL.md 反复调用
- 可信证据：真实制作过程；参考 Claude 官方 Skill 构建指南
- 必须保留的信息：小红书封面、Skill、SKILL.md、实操属性
- 当前推断与假设：这期内容的最大点击动力不是“什么是 Skill”，而是“终于开始亲手做一个 Skill”

## 二、4 套封面方向

### 方案 1｜核心产物展示

- 视觉类型：黑橙 3D 科技主体型
- 点击动机：把最终产物直接变成可识别的 3D 主体
- 主标题：手把手做一个小红书封面 Skill
- 副标题：从 0 到 1 完整实操
- 角标/可信标签：免费分享
- 信息层级：“小红书封面 Skill”最大；副标题与角标弱化
- 版式：上方白橙粗体标题，中下部为橙色发光 Skill 文件夹，深黑网格背景
- 画面建议：文件夹作为唯一 3D 主体，周围只保留少量图片、文字、魔法棒线性图标
- 可能有效的原因：产物清楚，科技感强，适合强调“做出一个可用 Skill”

### 方案 2｜完整流程拆解

- 视觉类型：蓝黄流程卡片型
- 点击动机：直接展示经验如何一步步变成 Skill
- 主标题：把封面经验变成 Skill
- 副标题：经验 → SOP → SKILL.md → 实测
- 角标/可信标签：完整流程
- 信息层级：“把封面经验变成 Skill”最大；流程卡片第二
- 版式：暖白纸张背景，上方黑色大标题与蓝色 Skill 色块，下方为蓝黄编号流程卡
- 画面建议：用 3–4 张真实纸质卡表达流程，黄色笔刷箭头连接，不堆叠代码
- 可能有效的原因：教程结构一眼可见，适合搜索与收藏导向

### 方案 3｜同一封面三次进化

- 视觉类型：米白红色前后对比型
- 点击动机：先看最终效果，再追问它如何被持续优化
- 主标题：同一封面，3 次进化
- 副标题：从草稿到高点击成品
- 角标/可信标签：前后对比
- 信息层级：数字 `3` 最大；“封面进化”第二；阶段图第三
- 版式：米白背景、红黑粗体标题，下方并排草稿、优化稿、成品三张阶段卡
- 画面建议：用红色箭头串联三个阶段，保留少量浅蓝笔刷做辅助，不使用人物
- 可能有效的原因：变化可视化，能快速建立结果期待

### 方案 4｜人物现场组装

- 视觉类型：荧光笔刷人物动作型
- 点击动机：用人物正在制作 Skill 的动作形成可读的故事瞬间
- 主标题：手把手做小红书封面 Skill
- 副标题：视频结尾分享
- 角标/可信标签：无
- 信息层级：荧光主标题最大；人物动作与 Skill 道具第二；白色副标题第三
- 版式：暗色真实工作室，人物居中把 Skill 文件递向镜头，标题在人物前后穿插
- 画面建议：人物动作必须由主题推导，不复制参考图中的扶额、托腮或视线
- 可能有效的原因：人物情绪、动作和道具共同表达“亲手做出并分享 Skill”

## 三、推荐方案

- 推荐：方案 4｜人物现场组装
- 推荐理由：人物正在操作与主题有关的 Skill 道具，既保留“手把手实操”的现场感，也能通过荧光笔刷标题在信息流里形成强识别；它只作为四种视觉类型中的一张，不改变另外三张。
- 建议保留的最终文案：
  - 主标题：手把手做小红书封面 Skill
  - 副标题：视频结尾分享
  - 角标：无

## 四、最终制作说明

- 画布与比例：竖版 3:4
- 核心视觉中心：荧光笔刷主标题与人物递出 Skill 文件的动作
- 文字排版：主标题拆成上下两个大块，与人物形成后景—中景—前景穿插；副标题缩小放在底部
- 主体画面：居中人物把与主题有关的 Skill 文件或文件夹递向镜头
- 背景与配色：暗色真实工作室，荧光黄绿色主标题，白色副标题
- 字体气质：粗粝手写笔刷字，保留毛边、飞白和速度感
- 素材要求：人物、Skill 文件、封面草稿或电脑；动作必须与制作主题有关
- 禁用项：复刻参考姿势、紫色渐变、绿色无衬线标题、悬浮 UI 卡片、普通微笑摆拍

## 五、验收结果

- 手机缩略图可读：通过；主标题需要分两行
- 一秒理解：通过；能理解“亲手制作并分享封面 Skill”
- 单一视觉中心：通过；荧光标题最醒目，人物动作和道具负责解释主题
- 可信证据真实：通过；“视频结尾分享”与实际内容一致，不夸大官方背书
- 无多余元素：通过；只保留人物、Skill 道具、主标题和一句副标题
- 封面与正文一致：通过
- 默认四种视觉组合正确：通过；前三种保持原视觉类型，第 4 种替换原紫绿人物科技型
- 荧光人物风格未扩散到前三张：通过
