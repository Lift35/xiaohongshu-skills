# 旁白驱动的知识视频制作

以真实录音决定“什么时候展示什么”，保留已确认的观点、设计与素材。默认交付烧录字幕的 MP4，同时提供独立 SRT；用户明确要求无字幕版本时才覆盖默认。

## 输入与边界

- 必需：录音，以及已确认 HTML 或已确认逐字稿＋分镜。建议同时取得对应逐字稿以校正术语。
- 按需：图片、真实操作录屏、素材使用约束。示意动画不能冒充真实操作。
- 可选：尺寸、帧率、字幕样式、品牌风格、制作范围。默认 1080×1920、30 fps，沿用既有设计，不强加某一期的配色。
- 确认录音覆盖范围、素材缺口和已有成果版本。缺录音时可准备静态画面，但不能称为已同步成片。部分录音只生成对应片段并明确标注，不编造剩余时间或配音。
- 只有稿件＋分镜时，先制作画面供用户确认，再同步导出；已有确认 HTML 时直接沿用。

## 流程

1. **预检**：确认音频可解码、字体可用、素材引用完整，以及语音识别、画面渲染和编码能力。使用环境实际提供的工具，不依赖未安装插件。外传录音、费用或新权限超出授权时先询问；明确访问禁止不能换路径绕过。普通依赖失败可使用获准替代方式并披露差异。
2. **对齐**：识别带时间戳的语音，结合逐字稿校正术语；以实际说出的内容为准，不把未读句子写进字幕。按真实语速、停顿和句意找提示点，不按字数平均分配时间。低置信识别、漏读或改变原意处标记复核；不能声称人工听过环境不支持读取的音频。
3. **统一时间轴**：读取 [时间轴与同步](references/timeline.md)。把页面、元素、素材和字幕映射到最终视频时间；预览和成片共用时间轴。逐步解释，不提前堆满整页内容。
4. **字幕与渲染**：读取 [字幕与验收](references/render-and-subtitles.md)。由同一字幕数据生成 HTML 字幕、烧录字幕和独立 SRT。运行 `python3 scripts/timeline.py timeline.json --srt subtitles.srt` 校验时间结构并导出字幕；该程序不负责识别或渲染。
5. **预览与导出**：优先共用视觉源。HTML 支持播放、暂停、跳转并恢复正确显隐状态。导出按帧求确定状态，不靠墙钟累积时间。记录实际渲染方式，替代重绘不能叫直接渲染原 HTML。本 Skill 是制作流程，不是自带的渲染引擎；须实际使用可用工具生成文件。
6. **验收与返修**：检查实际编码文件、关键句前后画面、字幕时间和布局。换录音后重对齐受影响内容并重算后续偏移，更新 HTML、视频与 SRT，不改无关稿件。失败时保留可编辑成果并说明缺项，不把损坏文件当成功交付。

## 默认交付

- 带烧录字幕 MP4：H.264、yuv420p、AAC。独立 SRT 不能移除已烧录字幕；需要重新设计字幕时额外导出干净视频，避免导入剪映后重复叠字。
- 同步 HTML：默认不自动播放，支持播放、暂停、进度跳转；附齐依赖或自包含，录制时可隐藏控制栏。
- UTF-8 SRT：与视频字幕同版本，另附实际样式参数；SRT 不保存字体、位置和描边。
- 时间轴 JSON：录音与素材版本、覆盖范围、待补段落和识别待复核项。
- 简短检查记录：时长、规格、实际渲染方式、检查范围、关键时刻、失败或待验证项。技术通过不等于内容与合规通过。

只做本次授权范围。不默认生成配音、音乐、新封面、重写稿件、发布或上传 GitHub。作为内容总控下游时接收已确认材料，返回成片、字幕及缺口，不重复选题、研究、写稿或专业审核。
