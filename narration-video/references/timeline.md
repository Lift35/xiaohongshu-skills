# 时间轴与同步

使用最终视频时间（秒，起点 0）作为唯一主时钟。媒体源有起始偏移、剪辑或变速时显式记录映射，不能把容器偏移直接混入字幕。

## JSON 合约

```json
{
  "version": 1,
  "duration": 10,
  "sources": [{"id": "voice", "file": "voice.m4a", "revision": "sha256-or-version"}],
  "coverage": {"included": ["page-1"], "omitted": ["page-2: 缺录音"]},
  "review": [],
  "cues": [
    {"time": 0, "page": "page-1", "visible": [], "anchor": "开场"},
    {"time": 4.95, "page": "page-1", "visible": ["tool-card"], "anchor": "这种 AI 能使用的工具"}
  ],
  "subtitles": [{"start": 4.95, "end": 8.2, "text": "这种 AI 能使用的工具\n就叫 Tool"}]
}
```

示例时间不可用于其他录音。每个 cue 保存完整显隐快照，不只存增量；时间严格递增，首项为 0，同一时刻变化合并。素材播放时补 media 对象，记录源 ID、源起点、视频起点及速率，预览导出共用映射。记录录屏插入后的时间偏移。

## 状态恢复

实现纯函数 stateAt(t)：取最后一个 cue.time <= t 的快照；字幕区间 start <= t < end，间隙清空字幕。动画进度由 t 和 cue 时间计算，不能依赖之前的播放事件。

HTML 以媒体 currentTime 为准；播放时逐帧刷新，seek、pause、loadedmetadata 也更新。倒退需隐藏未来元素；结束停在最后有效画面，不跳入未配音页。手动模式暂停音频或明确解除跟随。视频第 n 帧以 n/fps 求同一状态，取帧前等待字体和图片加载完毕。

## 重录和拼接

保留原始录音，重录按新版本重新对齐。多片段记录源入点、出点与最终偏移，检查接缝声音和字幕。默认不变速、不删除停顿、不替换口误音频；字幕不得偷偷改成另一事实，明显错误向用户指出。

辅助程序仅检查时间结构、区间和毫秒量化，不验证词是否说出、页面元素是否存在或语义同步，这些需另验。
